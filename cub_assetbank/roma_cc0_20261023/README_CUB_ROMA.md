# CUB / ROMA Shared 3D Asset Bank — 2026-10-23

This branch is an isolated asset staging library. Production code is untouched.

## What is physically included

56 actual, unmodified GLB binaries acquired directly from Hidencod/tge-assets (Kenney CC0 derivatives). See ASSET_MANIFEST.json for source and rights for each binary. The upstream LICENSE file explicitly declares CC0.

**Historical accuracy:** NOT VERIFIED. Some medieval and pirate models are placeholders/reference models only; do not pass off a fantasy ship or medieval fortification as an authentic Republican Roman asset. Uniform size and materials required.

**Primary uses:** round/oval test shields, sword/spear references, banners, cavalry horse placeholder, shipping movement, bridges, cliffs, rocks, crops, paths, pine trees, supplies, camps and building references.

**Not included:** detailed Roman helmets, historically correct Roman armour, fully rigged troops, PBR Poly Haven landscapes. No false claim that these were downloaded.

## CUB product direction — founder corrections

- Real-time grand campaign across continents, not turns. World geography must feel continental and alive, multiple city tiers, tactical wars inside same continuous world.
- Battle maps can be very large with several towns, bases and factions; keep AoE-style builders, gathering, technology, base construction, repairs and defensive works. American Conquest-type battle scale and duration.
- Troops animate on their own feet; NO display plinths, miniatures or pedestal soldiers. High-quality rigs and gaits, weapons properly attached, real proportions.
- Campaign economic model and battle gathering are not mutually exclusive: battle gathers local wood, food, stone etc; empire has regional production and taxation. Transfers abstracted through simple staging/supply rules; no heavy inventory spreadsheets.
- Cannae tactical core already fun: preserve and iterate rather than dismantle. Campaign geography/cities/terrain currently weakest.
- Performance: instancing, pooled units, level of detail, pathfinding on sectors and strategic zoom rendering; test before assuming 10k individually simulated units.
- Historical Republican 264–146 BCE equipment must avoid generic Imperial legion costumes and 104 BCE standard-icon anachronisms.

Do not send an implementation prompt: use this as product feedback and an asset source of truth for Claude.
